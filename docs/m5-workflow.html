2. Workflow del turista — Descubrir, valorar, compartir

sequenceDiagram
    autonumber
    actor T as Turista
    participant API as Backend
    participant DB as Supabase

    T->>API: POST /auth/register {email, pass, phone}
    API->>DB: signUp + insert profile
    DB-->>API: user creado
    API-->>T: access_token + refresh_token

    Note over T,API: Wizard de preferencias (opcional)
    T->>API: POST /preferences {tipo, presupuesto, ...}
    API->>DB: upsert user_preferences

    Note over T,API: Explora el directorio
    T->>API: GET /places?category_id&sort_by=rating
    API->>DB: query con joins + cover photos
    DB-->>API: listado paginado
    API-->>T: cards (foto, nombre, rating, precio)

    T->>API: GET /places/:id
    API-->>T: detalle + fotos + reviews

    Note over T,API: Acciones
    par Resena
        T->>API: POST /places/:id/reviews {rating, comment}
        API->>DB: insert review
        DB->>DB: trigger update_place_rating
    and Favorito
        T->>API: POST /places/:id/favorite
        API->>DB: toggle favorites row
    and Compartir
        T->>API: GET /places/:id/og
        API-->>T: metadata Open Graph
    end

3. Workflow dueño de negocio — Crear y gestionar micrositio

sequenceDiagram
    autonumber
    actor B as Business Owner
    participant API as Backend
    participant DB as Supabase

    B->>API: POST /auth/login
    API-->>B: token (rol=business)

    Note over B,API: Crear el lugar/negocio
    B->>API: POST /places {name, address, lat, lng,
cta_phone, cta_whatsapp}
    API->>DB: insert place (owner_id = B)
    DB->>DB: trigger places_set_slug
"La Trattoria" -> "la-trattoria"
    DB-->>API: place creado con slug
    API-->>B: place + slug

    B->>API: POST /places/:id/photos (galeria)

    Note over B,API: Crear promociones
    B->>API: POST /places/:id/promotions {title,
discount, starts_at, ends_at}
    API->>DB: ownership check + insert
    Note right of DB: Vista active_promotions
filtra is_active AND
now() entre fechas

    Note over B,API: Ver metricas
    B->>API: GET /places/:id/metrics/summary?from&to
    API->>DB: RPC place_metrics_summary
    DB-->>API: totales + comparativa periodo anterior
    API-->>B: dashboard data

    B->>API: GET /places/:id/metrics/timeseries?granularity=day
    API->>DB: RPC place_metrics_timeseries
    DB-->>API: buckets diarios
    API-->>B: serie temporal para grafico

5. Modelo de base de datos

erDiagram
    profiles ||--o{ user_preferences : tiene
    profiles ||--o{ places : posee
    profiles ||--o{ reviews : escribe
    profiles ||--o{ favorites : guarda
    profiles ||--o| business_notification_settings : configura

    categories ||--o{ places : clasifica
    places ||--o{ place_photos : contiene
    places ||--o{ reviews : recibe
    places ||--o{ favorites : aparece_en
    places ||--o{ promotions : ofrece
    places ||--o{ microsite_interactions : trackea
    promotions ||--o{ microsite_interactions : promo_view

    profiles {
        uuid id PK
        text email
        text full_name
        text phone
        text role
    }
    user_preferences {
        uuid user_id PK
        text traveler_type
        int budget_min_max
        bool wizard_completed
    }
    categories {
        uuid id PK
        text name
        text slug
        text icon
    }
    places {
        uuid id PK
        text name
        text slug "M5 UK"
        double lat_lng
        text cta_phone "M5"
        text cta_whatsapp "M5"
        text reservation_url "M5"
        numeric average_rating
        int total_reviews
        bool is_active
    }
    place_photos {
        uuid id PK
        text url
        bool is_cover
    }
    reviews {
        uuid id PK
        smallint rating "1-5"
        text comment
    }
    favorites {
        uuid user_id PK
        uuid place_id PK
    }
    promotions {
        uuid id PK
        text title
        smallint discount_percentage
        timestamp starts_at
        timestamp ends_at
        bool is_active
    }
    microsite_interactions {
        uuid id PK
        text interaction_type
        timestamp created_at
    }
    business_notification_settings {
        uuid user_id PK
        bool notify_call_click
        bool notify_whatsapp_click
        bool daily_summary
    }
