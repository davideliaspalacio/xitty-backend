5. Workflow M7 — Como se calcula el ranking (NUEVO)

flowchart TB
    INTER[(microsite_interactions
ultimos 30 dias)]
    PLACES[(places
average_rating)]

    INTER --> AGG[Aggregacion 30d:
views_30d + conversions_30d]
    PLACES --> SCORE
    AGG --> SCORE

    SCORE["Score por lugar:
0.4 * rating/5
+ 0.3 * min(views/1000, 1)
+ 0.3 * min(conv/100, 1)"]

    SCORE --> RANK[(place_rankings MV
RANK por categoria)]
    RANK --> SNAP[(ranking_snapshots
1 row/place/refresh)]

    CRON[pg_cron 03:00 BOG] -.refresh nightly.-> RANK
    ADMIN[POST /admin/ranking/refresh] -.refresh manual.-> RANK

    RANK --> Q1[GET /ranking]
    RANK --> Q2[GET /ranking/categories/:id]
    SNAP --> Q1
    SNAP --> Q2

    Q1 --> ORDER{Ordenamiento}
    Q2 --> ORDER
    ORDER --> SP[Sponsored primero
ordenados por score]
    ORDER --> ORG[Organicos despues
por position]

6. Workflow admin — Sponsored placements y contenido destacado (NUEVO)

sequenceDiagram
    autonumber
    actor A as Admin Xitty
    participant API as Backend
    participant DB as Supabase

    A->>API: POST /auth/login
    API-->>A: token (rol=admin)

    Note over A,API: Activar patrocinio (US-031)
    A->>API: POST /admin/places/:id/sponsorship
{duration_days: 30}
    API->>DB: UPDATE places SET
is_sponsored=true,
sponsored_until=now()+30d
    DB-->>API: place actualizado
    API-->>A: { is_sponsored, sponsored_until }
    Note right of API: Ranking lo promueve
al inicio con badge

    Note over A,API: Programar destacado semanal (US-032)
    A->>API: POST /admin/featured
{place_id, curator_name, week_*}
    API->>DB: insert featured_content
    Note right of DB: Vista current_featured
filtra por now() entre fechas
    API-->>A: featured creado

    Note over A,API: Forzar refresh (utilidad)
    A->>API: POST /admin/ranking/refresh
    API->>DB: SELECT refresh_place_rankings()
    DB->>DB: REFRESH MV CONCURRENTLY +
insert ranking_snapshots
    DB-->>API: ok
    API-->>A: { refreshed_at }

    Note over A,API: Quitar patrocinio expirado
    A->>API: DELETE /admin/places/:id/sponsorship
    API->>DB: UPDATE is_sponsored=false

9. User Stories cubiertas en M7

USHistoriaComo se resolvio
US-030 Como turista quiero ver el ranking dinamico de los lugares mas populares Materialized view place_rankings con score (rating + visitas + conversiones de 30d). Snapshots diarios para mostrar cambio de posicion.
US-031 Como negocio quiero pagar para aparecer destacado arriba en el ranking Campos is_sponsored + sponsored_until en places. Endpoints admin para activar/desactivar. Stripe queda para fase posterior.
US-032 Como Xitty/influencer quiero curar contenido destacado semanal Tabla featured_content con curator_name libre + ventana semanal. Vista current_featured filtra por fecha actual.
